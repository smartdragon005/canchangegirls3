# AI女友 - 多媒体聊天版

基于 DeepSeek API 的多角色 AI 女友聊天应用，支持文字、图片、语音交互。

## 功能特点

- 🤖 三个角色：甜小朵、白洁、小雅
- 💬 实时对话，带记忆（30回合）
- 📷 关键词触发图片（照片/自拍等）
- 🔢 数学关键词触发特殊图片（加减乘除/根号等）
- 🎵 关键词触发语音
- 👩‍❤️‍👩 角色互评（AI实时分析）

## 快速开始

1. 获取 [DeepSeek API Key](https://platform.deepseek.com/)
2. 打开 `index.html` 或访问 GitHub Pages 链接
3. 在输入框填入 API Key
4. 开始对话！

| 类型 | 关键词 |
